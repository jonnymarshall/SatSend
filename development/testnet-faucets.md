# Testnet4 faucets

Working faucets for topping up the testnet wallet (as of Oct 2026). Most other
testnet4 faucets were down or broken when this was last checked.

- https://coinfaucet.eu/en/btc-testnet4/
- https://testnet4.info/

Note that testnet coins have no value, and testnet4 is reset occasionally, so a
previously funded wallet can go empty without warning.
