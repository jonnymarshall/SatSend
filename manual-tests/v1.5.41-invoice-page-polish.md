# v1.5.41 — Invoice page polish

**Branch:** `fix/invoice-page-polish` · **Package version:** `1.5.41` · **Migration:** none

## Setup (once)

1. `git checkout fix/invoice-page-polish`
2. `npm run dev`
3. Sign in at http://localhost:3000 with your own account (test database).

## Quick smoke test

TEST 1, TEST 2 and TEST 4.

## TEST 1 — Fewer buttons on a sent invoice

**Proves:** the buttons fit on one line.

**Run:** open a sent (pending) invoice from the Invoices list.

**Expect:**
- One row: **View public invoice**, **Download PDF**, **Send** (if it's still offered), **⋯ More**. Nothing wraps on desktop.
- **More** opens: **Mark as paid** (plus Mark as overdue where it applies), a divider, **Archive**, **Duplicate**, **Delete**.
- **Delete** is greyed out, with "Only drafts can be deleted…" underneath.

## TEST 2 — The More menu works

**Run:**
1. On the TEST 1 invoice, choose **More → Mark as paid**.
2. **More** again: it now offers **Mark as unpaid**. Choose it.
3. **More → Archive**, then **More → Unarchive**.
4. **More → Duplicate**.

**Expect:**
1. The status becomes Paid.
2. Back to Pending.
3. Archived, then back to Pending.
4. The New Invoice form opens, filled in from the invoice.

## TEST 3 — Drafts

**Run:** open a draft.

**Expect:**
- Buttons: **Edit draft**, **Send**, **⋯ More**.
- **More** has **Duplicate** and **Delete**. Delete works on a draft and takes you back to the list.

## TEST 4 — Hand cursor in menus

**Run:** hover over the items in **More**, the **Send** menu, and the **⋯** menu on an Invoices list row.

**Expect:** a hand cursor on every item you can click. Greyed-out items show no hand.

## TEST 5 — SatSend's own "unsaved changes" box

**Run:**
1. **New Invoice**, type a client name, click **Cancel**.
2. Click **Keep editing**.
3. Click **Cancel** again, then **Discard changes**.
4. Open **New Invoice** and click **Cancel** without typing anything.

**Expect:**
1. A SatSend-styled box: "Discard unsaved changes?", with **Keep editing** and a red **Discard changes**. No "localhost:3000 says" box.
2. The box closes and your typing is still there.
3. You go back to the previous page.
4. You go straight back, with no box.

## TEST 6 — Phone width

**Run:** open the TEST 1 invoice in a narrow window (or the browser's phone view).

**Expect:** the buttons wrap neatly and **More** opens a menu that fits on screen.
