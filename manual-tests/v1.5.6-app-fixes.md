# v1.5.6 — App polish from the v1.5.5 test round: manual tests

**Branch:** `v1.5.6/app-fixes` · **Package version:** `1.5.6`

Note: until the marketing homepage ships (v1.5.2-H), `/` still forwards to the
invoices (signed in) or the login page (signed out). So a logo click lands there
for now; what matters is that every logo is clickable and points at `/`.

## TEST 1: Logo is a link everywhere

1. Signed in, on any app page, hover the logo top left.
2. **Expect:** hand cursor; the status bar shows `…/` (not `/invoices`); clicking
   it goes to `/` (which forwards to the invoices for now).
3. Open a client-facing invoice link (`/invoice/…`) in a private window; also one
   with an access code (the code screen); also `/login`.
4. **Expect:** on each, the logo is clickable and points at `/`.

## TEST 2: Hand cursor on buttons

1. Open an invoice from the list and hover "← Invoices".
2. **Expect:** the hand cursor. Other buttons (menus, copy, publish) also show it;
   disabled buttons do not.

## TEST 3: "Marked as sent manually" icon

1. Mark an invoice as sent manually, then look at it in `/invoices`.
2. **Expect:** a small grey paper-plane icon next to the status, the same icon
   as "Marked as sent" under Activity on the invoice page. Hovering shows
   "Marked as sent manually".
