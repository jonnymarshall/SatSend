# Release 1.6.1 (R-63) — "← Invoices" opens the invoice list

**Branch:** `r-63/back-link-after-save` · **Package version:** `1.6.1` · **Migration:** none

"← Invoices" at the top left of an invoice used to act like the browser's back
button, so after saving a draft it reopened the edit form. It now always opens
the invoice list, on the page of the list you were on.

## Setup (once)

1. `git checkout r-63/back-link-after-save`
2. `npm run dev`
3. Sign in at http://localhost:3000 with your own account (test database).
