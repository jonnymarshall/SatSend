# v1.5.22 — FAQ page: manual tests

**Branch:** `v1.5.22/faq-page` · **Package version:** `1.5.22` · **Migration:** none

## Quick smoke test

Run **TEST 1** and **TEST 2**.

## TEST 1: The page is real

1. **Run:** `npm run dev`, open the homepage, click **FAQ** in the menu.
   **Status check:** `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:3000/faq` prints `200`.
2. **Expect:** "Questions, answered."; five topic buttons; five groups (Getting
   started 5, Getting paid 7, Invoices 5, Security and privacy 4, Pricing 7);
   "Still have a question? Contact us"; the closing band.

## TEST 2: Jump links and answers

1. **Run:** click **Pricing** in the topic buttons; open a few questions.
2. **Expect:** the page scrolls to Pricing; answers fold open and closed. "Can I
   delete my account?" and "Can I get a refund?" link to `/contact`.

## TEST 3: One source for answers

1. **Run:** compare a homepage FAQ answer (e.g. "How do I know when I've been
   paid?") with the same one on `/faq`, and a Pricing page answer with `/faq`.
2. **Expect:** word for word the same.

## TEST 4: Phone width

1. **Run:** 390 × 844.
2. **Expect:** topic buttons wrap; each group's title sits above its questions;
   no sideways scrolling.

## TEST 5: Production (after merge)

1. **Run:** `curl -s -o /dev/null -w "%{http_code}\n" https://satsend.me/faq`;
   `curl -s https://satsend.me/faq | grep -c 'name="robots"'`.
2. **Expect:** `200`, then `0`.
