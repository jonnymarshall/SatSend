# v1.5.18 — How it works page: manual tests

**Branch:** `v1.5.18/how-it-works` · **Package version:** `1.5.18` · **Migration:** none

## Quick smoke test

Run **TEST 1** and **TEST 2**.

## TEST 1: The page is real

**Proves:** `/how-it-works` is the full page, reached from the menu.

1. **Run:** with `npm run dev` running, open `http://localhost:3000/`, then click
   **How it works** in the top menu.
   **Status check:** `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:3000/how-it-works` prints `200`.
2. **Expect:** headline "From invoice to bitcoin in your wallet"; four numbered
   steps (Create your invoice, Send it, Your client pays, You're told), each
   with a screenshot, alternating sides on desktop; a "What your client sees"
   panel; "What you'll need"; the dark "Start invoicing in bitcoin" band. No
   "Coming soon" anywhere.

## TEST 2: Phone width

**Proves:** the page works on a phone.

1. **Run:** dev tools → device toolbar → 390 × 844 (or a real phone).
2. **Expect:** each step stacks (text, then its picture); no sideways
   scrolling; the screenshots are readable enough to recognise each screen.

## TEST 3: Search engines may index it

**Proves:** the page is no longer hidden like the placeholders.

1. **Run:** `curl -s http://localhost:3000/how-it-works | grep -c 'name="robots"'`
2. **Expect:** `0`. (For comparison, `/pricing`, still a placeholder, prints `1`.)

## TEST 4: Production (after merge)

1. **Run:** `curl -s -o /dev/null -w "%{http_code}\n" https://satsend.me/how-it-works`, then open it.
2. **Expect:** `200` and the same page as TEST 1, with all four pictures loading.
