# v1.5.38 — Your own invoice pages use the SatSend reference

**Branch:** `v1.5.38/sender-invoice-links` · **Package version:** `1.5.38` · **Migration:** none

## Setup (once)

1. `git checkout v1.5.38/sender-invoice-links`
2. `npm run dev`
3. Sign in at http://localhost:3000 with your own account (test database).

## TEST 1 — Your invoice's address matches the client's

**Proves:** one invoice, one name in every link.

**Run:** on the Invoices list, click an invoice number. Note its SatSend
reference on the page (e.g. SS-YCDB27MX).

**Expect:** the address bar shows `localhost:3000/invoices/ss-ycdb27mx`, the
same reference as the client's link (`/invoice/ss-ycdb27mx`). No long id.

## TEST 2 — Edit and Duplicate

**Run:**
1. Open a draft and click **Edit**.
2. Open any invoice and click **Duplicate**.

**Expect:**
1. The address is `/invoices/ss-…/edit`.
2. The address is `/invoices/new?from=ss-…` and the form is filled in.

## TEST 3 — An old link still works

**Proves:** links saved before this change (bookmarks, old emails) don't break.

**Run:** open `localhost:3000/invoices/097198c0-49dc-42f0-9b79-ca92a01bcfde`
(the long-id link you mentioned on 2026-11-25; any old long-id link works).

**Expect:** a brief loading screen, then the address changes to
`/invoices/ss-ycdb27mx` on its own and the invoice shows.
