# v1.5.17 — Link-preview image: manual tests

**Branch:** `v1.5.17/og-image` · **Package version:** `1.5.17` · **Migration:** none

## Quick smoke test

Run **TEST 1** locally and **TEST 2** on production after the merge.

## TEST 1: The image looks like the site (local)

**Proves:** the preview uses the brand wordmark, fonts and colours.

1. **Run:** with `npm run dev` running, open `http://localhost:3000/opengraph-image`.
   **Status check:** `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:3000/opengraph-image` prints `200`.
2. **Expect:** a 1200 × 630 off-white card. Top left, the "SatSend.me" wordmark
   (".me" in amber). Below it, the small caps label "BITCOIN INVOICING FOR
   INDEPENDENT PROFESSIONALS", then the bold headline "Invoice in bitcoin." (dark)
   / "Paid straight to your wallet." (amber), as on the homepage. Bottom left,
   "Non-custodial · Zero transaction fees · Nothing to set up"; a thin amber
   strip along the bottom edge.

## TEST 2: Production

**Proves:** the fonts ship to production (the image would fail without them).

1. **Run:** `curl -s -o /dev/null -w "%{http_code}\n" https://satsend.me/opengraph-image`,
   then open the URL in a browser.
2. **Expect:** `200`, and the same image as TEST 1. Optionally paste
   `https://satsend.me` into a link-preview checker (for example opengraph.xyz).
   Chat apps cache previews, so an app that already showed the old image may
   keep it for a while.
