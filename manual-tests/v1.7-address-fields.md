# v1.7 — Proper address forms

**Branch:** `v1.7/address-fields` · **Package version:** `1.5.40` · **Migration:** `0041_structured_addresses.sql` (already applied to the test database)

Each address is now six fields: line 1, line 2, city, state / province / region,
post code and country. Every one is optional.

## Setup (once)

1. `git checkout v1.7/address-fields`
2. `npm run dev`
3. Sign in at http://localhost:3000 with your own account (test database).

## Quick smoke test

TEST 1, TEST 3 and TEST 7.

## TEST 1 — A new invoice with both addresses, everywhere it shows

**Proves:** the new fields save and print neatly on your page, the client's page and the PDF.

**Run:**
1. **New Invoice.** Under **You**: line 1 `1 Tower Bridge`, city `London`, post code `SE1 2UP`, country `United Kingdom`.
2. Under **Client**: line 1 `350 Fifth Avenue`, city `New York`, state `NY`, post code `10118`, country `United States`. Add a line item and a fresh testnet address.
3. Send it with **Copy link and mark as sent**.
4. Open your invoice page, then the client link (paste it), then **Download PDF**.

**Expect:** all three show:
- From: `1 Tower Bridge` / `London SE1 2UP` / `United Kingdom`
- To: `350 Fifth Avenue` / `New York, NY 10118` / `United States`

Each on its own line, with no blank lines between them.

## TEST 2 — Country search

**Run:** in a **Country** box, type `uni`. Then clear it with the **×** and type `kingdom`.

**Expect:**
- `uni` lists United Arab Emirates, United Kingdom, United States (names that start a word with "uni", so not Tunisia).
- `kingdom` finds United Kingdom.
- Clicking a country fills the box. Saving the draft and reopening it with **Edit** shows the same country.

## TEST 3 — An address with no post code or region

**Proves:** addresses from countries without post codes or regions fit with no gaps.

**Run:** new invoice, client address: line 1 `1 Queen's Road Central`, city `Central`, country `Hong Kong SAR China`. Leave line 2, state and post code empty. Save the draft.

**Expect:** the invoice page shows `1 Queen's Road Central` / `Central` / `Hong Kong SAR China`, with no blank lines.

## TEST 4 — Everything stays optional

**Run:** new invoice with only a city in the client address (nothing else in either address). Save the draft.

**Expect:** it saves with no errors and the page shows just the city.

## TEST 5 — An old invoice (not crucial)

**Run:** open an invoice made before this branch that had an address.

**Expect:** the old address appears on one line (it was moved into line 1), and **Edit** on a draft shows it in **Address line 1**.

## TEST 6 — Duplicate keeps both addresses

**Run:** on the TEST 1 invoice, click **Duplicate**.

**Expect:** the new form has both addresses filled in, including the countries.

## TEST 7 — Phone width

**Run:** open **New Invoice** in a narrow window (or the browser's phone view).

**Expect:** every address field is full width, one under another, and the country list opens and can be scrolled.
