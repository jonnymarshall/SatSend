## Honest limitations

- **Hooks are warn-only local feedback**; the *enforced* gate is CI on the PR.
- **version-sync derives the version from the branch name**, so it only fires on
  `vX.Y.Z...` branches, not `chore/...`. Acceptable for now.
- The hook *runtime* (Claude Code's JSON contract) can't be exercised from
  opencode; the scripts themselves are proven standalone (above).
- **opencode plugin parity deferred** — the repo has the plugin SDK but no plugin;
  add one only if the warns get ignored.
- To make CI unbypassable, enable branch protection requiring the check (and
  block direct pushes to `main`) — a GitHub settings click.
