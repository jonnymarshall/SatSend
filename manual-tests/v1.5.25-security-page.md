# v1.5.25 — Security page: manual tests

**Branch:** `v1.5.25/security-page` · **Package version:** `1.5.25` · **Migration:** none

## Quick smoke test

Run **TEST 1** and **TEST 3**.

## TEST 1: The page is real

**Proves:** `/security` is a full page, not "Coming soon".

1. **Run:** `npm run dev`, open the homepage, click **Security** in the footer
   (Product column).
   **Status check:** `curl -s -o /dev/null -w "%{http_code}\n" http://localhost:3000/security` prints `200`.
2. **Expect:** "Your bitcoin stays yours."; a row of six topic buttons (Your
   bitcoin, What we store, Your address, Access codes, Audit the code, Report a
   problem), each jumping to its section; six sections in this order: Your
   bitcoin never touches SatSend, What we store and what we'll never do, Your
   receiving address is protected, Access codes, Audit the code yourself, Found a
   problem?; then the dark "Start invoicing in bitcoin." band.

## TEST 2: Links

**Proves:** every link on the page goes somewhere sensible.

1. **Run:** click **Learn more about the FSL**, **View the code**, **contact us**
   and **open an issue on GitHub**.
2. **Expect:** fsl.software; "Coming soon" (until the SatSend GitHub account
   exists, roadmap v1.5.2.9-H); the Contact page ("Coming soon" for now);
   "Coming soon".

## TEST 3: Wording

**Proves:** the page never calls SatSend "open source", never mentions networks,
and shares the FAQ's licence wording.

1. **Run:** on `/security`, search the page (Cmd+F) for "open source", then
   "testnet". Then open `/faq`, Security and privacy, "Can I see SatSend's code?".
2. **Expect:** "open-source" appears once, only describing the Apache 2.0
   licence; "testnet" not found. The FAQ answer is "Yes." followed by the same
   words as the first paragraph of "Audit the code yourself".

## TEST 3b: Stores, never does, QR code

**Proves:** the agreed wording from review.

1. **Run:** read "What we store, and what we'll never do" and "How the QR code is made".
2. **Expect:** "What SatSend stores" says "At a minimum:" and then "Plus anything
   else you choose to add..."; the other list is "What SatSend will never do" and
   ends "See your wallet balance". The QR section says the client's own browser
   draws it, no outside QR service is involved, the software is only updated
   deliberately, and the address is printed beside it.

## TEST 4: Phone width

**Proves:** nothing overflows on a phone.

1. **Run:** open `/security` on your phone, or a 375px-wide browser window.
2. **Expect:** the headings sit above their text, the two lists (stores / will
   never do) stack, and the page never scrolls sideways.

## TEST 5: Search engines can find it

**Proves:** the page is no longer hidden from search.

1. **Run:** `curl -s http://localhost:3000/security | grep -o '<meta name="robots"[^>]*>'`
2. **Expect:** prints nothing (the "Coming soon" page had `noindex`).
