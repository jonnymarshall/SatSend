# v1.5.5 — Emails and PDF in Signal Amber: manual tests

**Branch:** `v1.5.5/emails-pdf` · **Package version:** `1.5.5`

Tip: emails sent from local dev show the logo only if the email app can reach
your computer, which it usually can't. For the logo, test from the live site
after merging.

## TEST 1: Invoice email

1. Publish a test invoice with "Send now via email" to your own address (check
   spam too).
2. **Expect:** the SatSend logo above a white card on an off-white background, the
   heading "Invoice … from …", a pale panel with Amount due (large), Due and the
   access code if set, an amber "View and pay" button with dark text, and the link
   written out underneath.
3. **Expect:** the inbox preview line reads "… has sent you an invoice for …".

## TEST 2: Payment emails

1. Pay a testnet invoice (or use one already paid) so the payment-detected and
   payment-confirmed emails send to you as owner and as payer.
2. **Expect:** a violet "Payment detected" pill, then a green "Paid" pill (orange
   "Underpaid" for a partial payment), an amber button, a "View transaction on
   mempool.space" link, and the transaction id in small grey type.

## TEST 3: PDF, unpaid

1. Download the PDF of a pending invoice (from the invoice page or the payer page).
2. **Expect:** the SatSend.me logo top left; "Invoice" and the number top right,
   with no status badge; a pale strip with Date Created and Date Due; From / Bill
   to; a calm item table; totals (the only place the amount appears), with the
   line above "Total" lined up with "Subtotal"; and a "Pay with Bitcoin" panel
   with the QR code, address and the payment link written out in dark text with
   an amber underline.
3. Select and copy some text. **Expect:** it pastes as normal words.

## TEST 4: PDF, paid

1. Download the PDF of a paid invoice.
2. **Expect:** a "Paid in bitcoin" panel with the transaction id (clickable, amber
   underline) instead of the QR code.

## TEST 5: Logo files

1. Open `public/brand/satsend-logo.svg` in a browser on a computer **without**
   Onest installed.
2. **Expect:** it looks exactly like the logo in the app header, with the same
   gap before `.me`.
